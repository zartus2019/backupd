Новое задание

Общая папка Windows (SMB) — источник
Шара будет смонтирована на сервере (cifs), затем скопирована rsync.
Windows через SSH — источник (OpenSSH Server + DeltaRSync)
rsync подтянет файлы с Windows по SSH: нужен ключ (ssh-copy-id user@windows). Одновременно с SSH-целью использовать нельзя (rsync поддерживает только один удалённый конец).
rsync-демон (rsyncd) — источник, без SSH
Модуль должен быть определён в /etc/rsyncd.conf на удалённой машине (порт 873 открыт в firewalld). Протокол не шифрует данные — используйте в доверенной сети.
FTP-сервер — источник (копирование через lftp mirror)
FTP-сервер запущен на источнике. Копирование выполняется lftp (команда mirror) — всегда одна актуальная копия, без снапшотов. Протокол не шифрует данные — используйте в доверенной сети.
Общая папка Windows (SMB)
На Linux должны быть установлены cifs-utils; служба выполняется от root (или с правами mount).
Windows через SSH (нужен OpenSSH Server и DeltaRSync на Windows)
Для SSH на Linux нужен ключ: ssh-keygen -t ed25519, затем ssh-copy-id user@windows (или добавить публичный ключ в %USERPROFILE%\.ssh\authorized_keys).
rsync-демон (rsyncd) — цель, без SSH
Модуль в /etc/rsyncd.conf должен разрешать запись (read only = no). Для rsyncd-цели снапшоты всегда полные копии (жёсткие ссылки на удалённой машине недоступны). Протокол не шифрует данные.
FTP-сервер — цель (копирование через lftp mirror)
Копирование выполняется lftp (команда mirror) — всегда одна актуальная копия, без снапшотов. Протокол не шифрует данные — используйте в доверенной сети.
Для инкрементального режима: раз в N дней снапшот делается полностью (без ссылки на предыдущий).
